# 🌙 Soothing English Storytime (Repository 7 / Variety 7)

Automated video generator for **Relaxing Bedtime & Comprehension Stories** in 1920x1080 landscape format.

## 🌟 Key Features
- **Relaxing Twilight Aesthetic**: Ambient starry background with calming color scheme.
- **Slow Narrative Pace**: `-20%` speed with soothing native narrator voice (`en-US-AvaNeural`).
- **Dual-Pane Layout**: Main narrative passage on the left + interactive Vocabulary Spotlight glossary cards on the right.
- **High Watch-Time Retention**: Ideal for evening learners, sleep immersion, and relaxation.

## 🚀 How to Run
```bash
# 1. Generate story video
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/story_listening_final.mp4 output/run_XXXX/metadata.json
```

## 📱 Recommended Facebook Page Target
- **Page Concept**: *English Storytime / Sleep & Learn English*
- **Target Audience**: Viewers who want peaceful, relaxing listening sessions before bedtime or during study focus.
